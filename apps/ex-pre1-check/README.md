# 単熟語EX準1級 定着チェック（作り直し版）

スタスタLIVE英検の生徒が「単熟語EX準1級 第2版」の語を、意味を思い出せるか・日が経っても答えられるかで確認するアプリ。
1つのHTMLファイルで動き、記録はブラウザ（localStorage）に保存する。

## リポジトリに入れていないもの（重要）

このリポジトリは公開（public）設定です。内蔵の単語データ（2,412項目）は出典の利用範囲が
「個人・教育現場での確認テスト用。ウェブへの転載・販売はしません。」のため、**単語データと完成HTMLはコミットしていません**（`data/` と `dist/` は .gitignore 対象）。
完成HTMLは、手元の元HTMLから下の手順で作ります。

## 作り方

```bash
python3 -I tools/extract_data.py <元HTML: 単熟語EX準1級_定着チェック.html>   # → data/words.json
python3 -I tools/build.py                                                     # → dist/単熟語EX準1級_定着チェック.html
```

番号・英語・訳語は元HTMLの `BUILTIN_WORDS` をそのまま使い、推測で作り直していません。

## 検算（3段階）

```bash
node tools/verify_data.mjs <元HTML>        # ① 完成HTMLの内蔵データが元HTMLと全件一致するか
node --test tests/core.test.mjs             # ② 判定・出題・移行ロジック（17項目）
node tests/e2e.mjs <元HTML> [出力先]        # ③ 画面の通しテスト（スマホ幅390px、19項目。スクリーンショットと紙テストPDFを出力）
```

③は旧アプリ（元HTML）を実際に操作して記録を作り、その記録を新アプリへ移す手順まで確認します。
Chromium が必要です（`PW_CHROMIUM` で実行ファイルを指定可）。

## 構成

| ファイル | 内容 |
| --- | --- |
| `src/core.js` | 定着判定・出題・4択の選択肢・CSV取込・旧形式からの移行・報告の集計（画面に依存しない） |
| `src/app.js` | 画面 |

## 引き継ぎ資料との対応

### 既存機能（引き継ぎ・確認済み）
- 4形式（意味を思い出す／4択／英語を書く／本と一緒に確認）、自信3段階、思い出せない、回答時間の記録（判定には不使用）
- 定着段階 0〜5、24時間→3日→7日、14日後の再確認、予定前の反復では進まない、再確認待ちは定着確認済みから除外
- 正答率の分子は「正解」のみ、あいまい0.5は正解数に含めない
- 中断・再開、ここまでを保存して終了（未回答は分母に入れない）、要復習の語だけ再テスト、結果CSV
- 単語リストの検索・絞り込み・CSV/TSV/貼り付け取込・CSV書き出し・テンプレート
- 学習者の追加・切り替え・改名（上限100人）、JSONバックアップの保存・復元、紙テストの印刷と結果登録

### 改善（引き継ぎ資料の指摘への対応）
- **4択の対象語**：4択は4択自身の記録（recognition）で「未確認・苦手」を選ぶ。4択には復習日がないため「復習日を迎えた語だけ」は選べない。作成画面に基準を表示。
- **4択の誤答選択肢**：訳語の完全一致に加え、漢字2字の共通・カタカナ語の共通・包含関係がある語を除外。同じ英語の別項目（decode 803/2256）も除外。範囲内で足りなければ全項目から補う。誤答同士の重なりも避ける。同義語までは機械判定できないため「選択肢に問題がある」報告ボタンを追加（報告した問題は記録しない、設定画面でCSV保存）。
- **空の区分**：旧版の復元処理が区分「単語」・本と一緒に確認を既定にしていた点を修正。データのない版・区分を指す設定は第2版／全項目に戻す。
- **日本語入力中のEnter**：Enterでは送信しない（キーボードを閉じるだけ）。回答の確定は「自信」ボタンで行う。
- **移行**：旧形式（version 1）のバックアップ・同じブラウザ内の旧記録を新形式へ変換。読めない項目は捨てずに理由つきで一覧表示し、元の値を保存できる。旧記録自体は消さない。

### 追加（今回の提案。元からあった機能ではない）
- **先生への報告画面**：学習者名・日付・実施数・形式別の正答率・範囲・要復習語・次の復習・定着状況を1画面に表示。LINE用の報告文コピー、画像（PNG）保存・共有。
- 英語を書く：訳語がまったく同じ別項目の英語も正解（例：mandatory / compulsory）。表記違いを先生確認で正解に直すボタン。
- 紙テストを保存しておき、後から1問ずつ採点できる（旧版はダイアログを閉じると採点が消えた）。
- 学習者の削除、ホームのワンタップ開始（今日の復習／未確認の語／苦手な語）。

## 保存

- localStorage キー：`stasta-ex-check-v2`（データ形式 version 2）。旧アプリの `stasta-ex-check-v1` は読み取るだけで変更しない。
- 内蔵単語データは保存領域に複製しない（追加登録した単語のみ保存）。

## 要確認（自動検算できていない項目）

1. **実機での操作**：検証はヘッドレスChromiumのスマホ幅のみ。iPhone Safari・Android Chrome での日本語入力（Enter）、画像の共有シート、印刷、ホーム画面追加時の動作は未確認。
2. **4択の同義語**：「捨てる」と「処分する」のように文字が重ならない同義語は除外できない。実際の出題で気になるものは報告ボタンで集めて確認が必要。
3. **内蔵訳語と書籍原本**：元データの時点で原本との全件照合記録がない（引き継ぎ資料のとおり）。また元データ内に、英語が同じ項目（No.803 と No.2256 の decode）と、訳語が完全一致する別項目9組がある。照合で直すかは書籍で確認。
4. **英語を書く形式の出題文**：日本語訳だけでは複数の英語が当てはまる語がある。別解データは元から空。
5. **報告画面の文言・見た目**：先生がスマホで読みやすいか、保護者・生徒に見せて違和感がないか。
6. **旧記録の自動検出**：旧アプリと同じブラウザ・同じ置き場所（同じオリジン）で開いた場合だけ検出される。そうでなければ旧アプリでバックアップJSONを保存して読み込む。
