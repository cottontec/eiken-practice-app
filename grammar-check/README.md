# スタスタLIVE英検 英文法チェック

英検5級〜1級の英文法を診断するWebアプリです。`index.html` をブラウザで開けば動きます。ビルドもサーバーも不要で、静的ホスティングにそのまま置けます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（開始画面 → 出題 → 結果） |
| `questions.js` | 問題バンク（7級×20問＝140問。選択肢ごとに正誤の根拠つき） |
| `verify.mjs` | 照合スクリプト（形式チェック＋ブラウザでの通し検算） |
| `review-sheet.md` | `verify.mjs` が書き出す校閲用シート（全問・全選択肢の根拠一覧） |

## 仕様

- 級を選ぶと20問を出題します。順番と選択肢の並びは毎回シャッフルします。
- 1問ごとに ○／× を表示し、4つの選択肢すべてに正誤の根拠を表示します。
- 結果画面には、正答数、分野別の正答（低い順。60%未満に「要復習」）、まちがえた問題の解説を表示します。
- 「結果をコピー」で、なまえ・級・正答・分野別・要復習の分野をまとめた文面をコピーできます（LINEで講師に送る想定）。
- なまえと最後に選んだ級は、その端末のブラウザにだけ保存されます。サーバーには送信しません。

| 級 | 形式 | 問題数 |
|---|---|---|
| 5級・4級 | 4択（短文の語句空所補充）＋並べ替え（日本文付き短文の語句整序） | 15＋5 |
| 3級・準2級・2級 | 4択 | 20 |
| 準1級・1級 | 4択（語法・構文） | 20 |

### 形式の根拠

英検公式の各級「試験内容」ページ（検索結果の抜粋で確認）にもとづいています。

- 5級・4級は「短文の語句空所補充 15問」と「日本文付き短文の語句整序」を出題する（5級の語句整序は5問）。
- 3級の大問1は「短文の語句空所補充 15問」。並べ替えは現行の3級以上では出題されないため、3級以上は4択のみにしています。
- 2024年度の改定で、準2級以上の大問1は問題数が減っている。準1級・1級の大問1は語彙問題が中心です。そのためこのアプリの準1級・1級は「長文・英作文で必要な語法・構文の確認」と位置づけています。

## 検算

```
node verify.mjs          # 形式チェック＋ review-sheet.md の書き出し
node verify.mjs --e2e    # 上記＋ブラウザ（Playwright）で全級を全問正解／全問不正解で通しで解き、結果画面を照合
```

自動でチェックする項目
- 級ごとの4択／並べ替えの問題数
- ID・英文の重複
- 空所がちょうど1つあるか
- 選択肢が4つで重複がないか
- 正解の添字が有効か
- 4つの選択肢すべてに根拠があるか
- 文頭の空所の正解が大文字で始まるか
- 並べ替えの語句が4つで重複がないか、文頭の語も小文字か（本番の表記どおり）
- 画面上の選択肢がデータと一致するか
- ○／×の判定と、結果画面の正答数・分野別合計・まちがえた問題の件数が合っているか
- スマホ幅（360px）で横スクロールが出ないか
- スクリプトエラーが出ないか

## 要確認（自動では検算できない項目）

1. **英文の自然さ**：全140問は自作です。作成役と粗探し役の二段で点検しました（粗探し役の指摘20件はすべて反映済み）が、ネイティブチェックは未実施です。特に以下は英米で容認度が分かれうる箇所です。
   - gp1-09・g1-08・g1-09（仮定法現在）：イギリス英語では should＋原形や直説法も使われます。選択肢はどの用法でも誤りになるものに限定しました。
   - g1-07（would rather＋過去形）：口語では現在形も聞かれます。現在形は選択肢から外しました。
   - g2-04（It's time＋過去形）：くだけた話し言葉では現在形もまれに聞かれます。
2. **級のレベル適合**：語彙・構文・トピックを目視で判定しています。特に準1級・1級は本番に文法単独の問題がほぼないため、出題範囲の妥当性を講師の目で確認してください。
3. **1回の問題数（20問）と「要復習」の基準（60%）**：どちらも【仮置き】です。参考アプリ（stasta-eiken-vocab-check）の問題数に合わせる予定でしたが、作業環境から参考アプリに接続できず、確認できていません。
4. **見た目**：参考アプリの配色・レイアウトに合わせていません（同上の理由）。
5. **並べ替えの答え方**：本番は「2番目と4番目の組み合わせを4択で選ぶ」形式です（5級は「1番目と3番目」。この細部は公式ページ未確認）。このアプリは、診断のために4語句すべてを並べさせる形式にしています。
6. **正解位置の偏り**：データ上の正解位置は2番目に偏っています。画面では毎回シャッフルするため、受験者には影響しません。紙に印刷して使う場合は並べ替えてください。
