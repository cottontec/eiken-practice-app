# 監査依頼（ChatGPT 用）

あなたは英検の問題を校閲する独立監査人です。添付の問題バンク（英検5級〜1級の英文法問題、各20問・計140問）を監査してください。ファイルは修正せず、指摘だけを返してください。

## 添付ファイル

| ファイル | 内容 |
|---|---|
| `bank.json` | 問題バンク本体（監査対象） |
| `review-sheet.md` | 全問・全選択肢の正解と根拠を一覧にしたもの（人が読む用） |
| `verify_bank.py` | 形式チェックスクリプト |
| `README.md` | アプリの仕様、出題形式の根拠（英検公式ページ）、要確認リスト |
| `LOG.md` | 過去の監査ラウンドの指摘と対応結果（同じ指摘をくり返さないために参照） |

`bank.json` の構造
- `type: "choice"`：`en` は英文で、空所を `(　　)` で示す。`choices` は選択肢4つ、`answer` は正解の添字（0始まり）、`ja` は和訳、`why` は選択肢ごとの正誤の根拠（`choices` と同じ順）。
- `type: "order"`：`ja` は日本文、`before`／`after` は空所の前後の固定語句、`tokens` は正しい順に並べた4語句（本番どおり、文頭の語も小文字）、`why` は解説。

## 手順（この順で）

1. **スクリプト実行**：`python3 verify_bank.py bank.json` を実行し、出力をそのまま貼る。不合格があればそれも指摘に含める。
2. **要確認リストの目視**：`README.md` の「要確認」の各項目について、妥当か・追加の懸念はないかを書く。
3. **原本照合**：全140問を1問ずつ確認する。観点は下表。

| 観点 | 確認すること |
|---|---|
| A. 正解の一意性 | 正解以外の3つが、米英どちらの標準的な用法でも確実に誤りか。意味が変わっても文法的に成り立つ別解や、口語で広く使われる形も別解として指摘する。 |
| B. 英文 | 自然さ、文法の誤り、コロケーションのずれ。 |
| C. 和訳 | `ja` は正確か。 |
| D. 根拠 | `why` の文法説明に誤りはないか。 |
| E. 級のレベル | 語彙・構文・トピックが級に合っているか。目安は5級=中1、4級=中2、3級=中3、準2級=高校中級、2級=高校卒業、準1級=B2、1級=C1。易しすぎ・難しすぎの両方を指摘する。 |
| F. 並べ替え | 日本文と一致し、4語句の並べ方が一通りに決まるか。 |
| G. 出題形式 | 英検の実際の形式（指示文、語数、選択肢の形）からずれていないか。 |

## 返答の形式

最初に、手順1・2の結果を短く書く。

その後に、手順3の指摘を **次の JSON 配列だけで** 返す（コードブロックで囲む）。問題がない問題は含めない。

```json
[
  {
    "id": "gp2-14",
    "severity": "要修正 | 要検討 | 軽微",
    "aspect": "A | B | C | D | E | F | G",
    "problem": "何が問題か（日本語、具体的に。別解なら成り立つ英文を書く）",
    "fix": {
      "en": "修正後の英文（変える場合のみ）",
      "choices": ["修正後の選択肢4つ（変える場合のみ）"],
      "answer": 0,
      "ja": "修正後の和訳（変える場合のみ）",
      "why": ["修正後の根拠4つ（変える場合のみ）"]
    },
    "confidence": "高 | 中 | 低"
  }
]
```

最後に「問題なしと判断した問題数」を書く。

## 注意
- 自信のない指摘は `confidence: "低"` にする。断定しない。
- 修正案の英文も、同じ観点A〜Gで自己点検してから出す（修正案が新たな別解を生まないこと）。
- `LOG.md` で「見送り」とした指摘を再度出す場合は、見送り理由への反論を `problem` に書く。
