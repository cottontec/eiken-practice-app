- **◎ was taking** … 過去のある時点にしていた最中の動作なので過去進行形 was taking。


和訳：私には兄弟が3人いて、全員が海外に住んでいる。

- × who … 前置詞 of の後ろには目的格 whom を置く。
- **◎ whom** … 先行詞が人（brothers）で前置詞 of の後ろなので whom。
- × them … them だと接続詞がないまま2つの文がコンマでつながってしまう。
- × which … which は先行詞がもののときに使う。

### g1-14［分詞構文］

```
The proposal was rejected, the reason (　　) that it was too costly.
```

和訳：その提案は却下された。費用がかかりすぎるというのが理由だった。

- **◎ being** … 意味上の主語 the reason を残した独立分詞構文 the reason being that 〜。
- × been … been だけでは分詞構文にならない。
- × be … be（原形）だけでは分詞構文にならない。
- × to be … the reason to be that 〜 という形はない。

### g1-15［慣用構文］

```
(　　) it to say that the project was a disaster.
```

和訳：その計画は大失敗だったとだけ言っておこう。

- **◎ Suffice** … Suffice it to say that 〜（〜とだけ言えば十分だろう）は仮定法現在の決まった表現。
- × Sufficient … 形容詞 Sufficient は it を目的語にとれない。
- × Sufficing … Sufficing では文の動詞にならない。
- × To suffice … To suffice では文の動詞にならない。

### g1-16［不定詞・動名詞］

```
There is no denying (　　) the project was a failure.
```

和訳：その計画が失敗だったことは否定できない。

- **◎ that** … There is no -ing（〜できない）。denying の目的語になる名詞節 that。
- × what … what の後ろは欠けた要素がある文になる。ここは完全な文。
- × which … which は先行詞が必要。
- × it … it と the project was ... の間をつなぐ語がない。

### g1-17［比較］

```
The more I learned about him, the (　　) I trusted him.
```

和訳：彼について知れば知るほど、彼を信頼しなくなった。

- × little … the＋比較級, the＋比較級 の形なので原級 little は不可。
- **◎ less** … little の比較級 less。「信頼の程度」は数えられないので less。
- × least … least は最上級。
- × fewer … fewer は数えられる名詞の数に使う。

### g1-18［比較］

```
He is not so much a scholar (　　) a writer.
```

和訳：彼は学者というよりむしろ作家だ。

- **◎ as** … not so much A as B で「AというよりむしろB」。
- × than … not so much は as と組む。than は不可。
- × but … not A but B とは別の構文。so much とは組まない。
- × so … so は組み合わせとして誤り。

### g1-19［譲歩］

```
Granted (　　) he is talented, he still needs more practice.
```

和訳：確かに彼には才能があるが、それでももっと練習が必要だ。

- **◎ that** … Granted that 〜 で「確かに〜だとしても」（譲歩）。
- × what … what の後ろは欠けた要素がある文になる。ここは完全な文。
- × which … which は先行詞が必要。
- × if … Granted if という形はない。

### g1-20［倒置］

```
Not a single word (　　) during the meeting.
```

和訳：彼は会議中、一言も話さなかった。

- **◎ did he say** … 否定語句 Not a single word が文頭にくるので倒置 did he say。
- × he said … 倒置になっていない。
- × said he … 一般動詞をそのまま主語の前に出すことはできない。
- × he did say … did が主語の後ろにあり、倒置になっていない。
