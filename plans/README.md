# plans/ — 学習計画ドキュメント

生徒に共有する学習計画を、編集しやすいHTMLソースと配布用PDFのペアで管理します。

## ファイル

| ファイル | 役割 |
|---|---|
| `英検2級_S-CBT_学習計画.html` | 学習計画の編集用ソース（緑テーマ・A4印刷用CSS） |
| `英検2級_S-CBT_学習計画.pdf` | 配布用PDF（HTMLから生成） |
| `generate.sh` | HTML → PDF 変換スクリプト |

## PDFの再生成

```bash
cd plans
./generate.sh "英検2級_S-CBT_学習計画"
```

- Chromium（Playwright同梱の `/opt/pw-browsers/chromium-*/chrome-linux/chrome` でも可）と
  日本語フォント（`IPAGothic` 等）が必要です。
- `CHROME=/path/to/chrome ./generate.sh ...` でブラウザを明示指定できます。

## 注意（このS-CBT計画について）

`英検2級_S-CBT_学習計画.*` は、共有された学習計画の**画像をもとに書き起こした**ものです。
満点・合格基準点は英検2級の公式値（各技能650／3技能合計1950／合格基準 一次1520・スピーキング460）を使用しています。
次の項目は原本と細部が異なる可能性があるため、確定値が分かり次第HTMLを更新してPDFを再生成してください。

- 受験日
- 各技能の目標サブスコア
- 24コマそれぞれの具体的なテーマ
