# 固有名詞の別表記を（）で併記する作業の指示書

目的：読み方・呼び名で迷う固有名詞に、別の表記を（）で添える。生徒が教科書やネットで別の表記を見ても、同じものだと分かるようにする。

## 対象
- 各回の `work/<batchId>/_review.md` の「## 要確認」に挙がっている項目のうち、固有名詞（人名・地名・団体名・作品名・書名・船名・生物名）の表記についての項目で、別の候補がはっきり書かれているもの。
  - 例：「Enzo を『エンゾ』とした（『エンツォ』とも）」→ 対象
  - 例：「Julius Caesar を『ユリウス・カエサル』とした（英語読みは『ジュリアス・シーザー』）」→ 対象
  - 例：「Jemima を『ジェマイマ』とした（冊子に読みなし）」のように、別の候補が書かれていないもの → 対象外（候補を自分で作らない）
- 一般の語の訳語（「喫水線」「準備通貨」など）、比較の補い、訳の読み方の項目は対象外。

## 書き方
- 形：`いまの表記（別の表記とも）`。例：`エンゾ（エンツォとも）`、`ユリウス・カエサル（ジュリアス・シーザーとも）`
- いまの表記（主）は変えない。別の表記を添えるだけ。
- 日本で定着した呼び名がある場合、主がその呼び名になっていなければ、別の表記として必ず添える（例：`フィリスティア（ペリシテとも）`）。
- 1つのファイルにつき、その名前が日本語の文に最初に出てくる1か所だけに添える。英文の引用の中には入れない。
- 長文（大問2・3）に出てくる名前は、`<unitId>.passage.txt`（本文全訳）にだけ添える。問題ファイルには、全訳がそのまま差し込まれるので添えない。
- 短文（大問1）の名前は、その問題ファイル（`<questionId>.txt`）の【和訳】の訳文に添える。
- 該当する名前が見つからない場合は、何もしない。

## 作業のあと
- 併記した項目は、`_review.md` の該当の要確認の行の末尾に `→（～とも）を併記済み` と書き足す（見出しは変えない）。
- 回ごとに次を実行し、ERROR 0・WARN 0 を確認する。
  `python3 -I /home/user/eiken-practice-app/reading_explanations/tools/build_and_check.py --src-root /tmp/claude-0/-home-user-eiken-practice-app/37990840-d70a-5962-afc7-2daeb13275d4/scratchpad/zips --part <分割番号> --batch <batchId>`
- これ以外の書き換えはしない。git の操作はしない。

## 報告
回ごとの併記件数と、迷って併記しなかった項目（理由つき）を簡潔に。
