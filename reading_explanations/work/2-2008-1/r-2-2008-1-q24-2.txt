【正解】3 you（この問題の2番目）
【完成文】
Don't give up so easily, Randy. ( If you stick to it ), I'm sure you'll improve.
並べ方：4 if → 3 you → 2 stick → 1 to → 5 it（2番目は3、4番目は1）
【和訳】
A：コーチ、私はバレーボールがあまりうまくできていません。チームをやめたほうがいいかもしれません。
B：そんなに簡単にあきらめるな、ランディ。あきらめずに続ければ、きっと上達すると思うよ。
【考え方】
空所のあとにコンマがあり、I'm sure you'll improve（きっと上達すると思う）と文が続いています。そこで空所には「～すれば」という条件を表すまとまりが入ると考え、4 if を先頭に置きます。
if のあとには〈主語＋動詞〉がきます。主語は 3 you、動詞は 2 stick です。stick to ～ は「～をあきらめずに続ける、～をやり通す」という意味なので、そのあとに 1 to と 5 it を続けます。it はバレーボール（の練習）を指しています。こうして If you stick to it（それをあきらめずに続ければ）が完成します。
Aは「バレーボールがあまりうまくできないので、チームをやめたほうがいいかもしれない」と言い、Bは Don't give up so easily（そんなに簡単にあきらめるな）と答えています。「あきらめずに続ければ上達する」という流れになり、意味が通ります。
you stick it to のように it と to の順番を逆にすると、stick to ～ の形がくずれます。to のあとに it を置くことに注意します。
したがって2番目は3 you です。
【覚えるポイント】
・stick to ～：「～をあきらめずに続ける、～をやり通す」。
・I'm sure (that) ～：「きっと～だと思う」。
