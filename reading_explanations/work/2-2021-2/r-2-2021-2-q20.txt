---
choices: all the more | all the best | all the better | all the most
answerText: all the more
---
【正解】1 all the more（なおさら、いっそう）
【和訳】
シュンタロウはいつも、チェス部のほかの部員たちを助けようとしてきました。今年になって部長になってからは、（なおさら）そうしています。
（選択肢の意味）1 なおさら、いっそう　2 ごきげんよう、お元気で（別れのあいさつ）　3 それだけいっそうよい　4 （このような決まった言い方はない）
【考え方】
1文目は Shuntaro has always tried to help the other members of the chess club.（シュンタロウはいつも、チェス部のほかの部員たちを助けようとしてきた）です。
2文目は He has been doing so (　) since he became the club's president earlier this year. です。doing so（そうすること）は、1文目の「ほかの部員を助けようとすること」を指します。since ～ は「～して以来」、earlier this year は「今年に入って（今より前に）」という意味です。
部長になる前から部員を助けようとしてきたのですが、部長になってからは、その気持ちや行動が前よりも強くなったと考えると自然です。all the more は「（それだけ）なおさら、いっそう」と、量や程度が前より増えたことを強める言い方です。He has been doing so all the more で「なおさらそうしている」となるので、1が正解です。
【ほかの選択肢】
2 all the best は「ごきげんよう、お元気で」という、手紙の終わりや別れのときのあいさつです。文の途中で「そうしている」を強める言い方にはなりません。
3 all the better は「それだけいっそうよい」と、よしあしについて言う決まった言い方です。That's all the better.（それならなおさら好都合だ）のように使います。ここでは「助けようとすることを、前よりもっとしている」という程度が増えたことを言いたいので、more を使う all the more が合います。
4 all the most という決まった言い方はありません。
【覚えるポイント】
・all the more：「なおさら、いっそう」。all the more because ～（～なのでなおさら）の形でもよく使います。
・doing so：前に出た動作を受けて「そうすること」を表します。
