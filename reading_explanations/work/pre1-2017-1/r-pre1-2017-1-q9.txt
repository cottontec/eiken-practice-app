【正解】3 intermittently（断続的に、ときどき止まりながら）
【和訳】
（英文）
A: Elena, the weather forecast says it will rain today, so maybe we should do some gardening another day.
B: It's only supposed to rain ［intermittently］, honey. Let's just do as much as we can before it starts.
（訳）
A：エレナ、天気予報によると今日は雨が降るそうだから、庭仕事は別の日にしたほうがいいかもしれないね。
B：ねえ、雨は（降ったりやんだり）するだけの予報だよ。降り出す前に、できるだけやってしまおう。
（選択肢の意味）
1 solemnly：おごそかに、まじめに
2 courteously：礼儀正しく
3 intermittently：断続的に（ときどき止まりながら）
4 recklessly：向こう見ずに、無謀に
【考え方】
まず見るところ：Bの It's only supposed to rain ( ) と Let's just do as much as we can
Aは、雨が降るので庭仕事は別の日にしようと言っています。Bの答えは次のとおりです。
It's only supposed to rain ( ), honey.（ねえ、雨は（　）降るだけの予報だよ）
be supposed to ～ は「～することになっている、～の予定だ」、only は「～だけ」です。honey は家族など親しい相手への呼びかけです。
Bは続けてこう言っています。
Let's just do as much as we can before it starts.（降り出す前に、できるだけやってしまおう）
Bは庭仕事をやめずに、雨の前にできるだけやろうと言っています。ですから、Bは「雨は一日じゅうずっと降るわけではない」と伝えたいのだと考えられます。intermittently は「断続的に（降ったりやんだりして）」という意味なので、3が正解です。
この問題の型：語の意味・組み合わせ（rain と intermittently）／推論（庭仕事を続けようと言う理由）
【ほかの選択肢】
1 solemnly は「おごそかに、まじめに」です。人の態度や儀式の様子に使う語で、雨の降り方には合いません。
2 courteously は「礼儀正しく」です。これも人の態度を表す語で、「雨が礼儀正しく降る」では意味が通りません。
4 recklessly は「向こう見ずに、無謀に」です。人の行動を表す語で、雨の降り方には合いません。また、庭仕事を続けてよい理由にもなりません。
【覚えるポイント】
・intermittently：「断続的に（ときどき止まりながら）」。
・相手の提案（別の日にしよう）に反対する答えでは、only などで「それほど困ったことではない」と伝えていることが多いので、反対する理由になる語を選ぶと手がかりになります。
