choices: seize | omit | thaw | insure
answerText: omit

【正解】2 omit（省く、抜かす）
【和訳】
（英文）
A: Honey, I want to call Cindy to see how she's doing in Japan. The code for Tokyo is 03, right?
B: Yes, but you need to ［omit］ the first number as it's an international call. Just dial 3, not 03.
（訳）
A：ねえ、シンディに電話して、日本でどうしているか確かめたいの。東京の市外局番は03だよね？
B：そうだよ。でも、国際電話だから、最初の数字を（省く）必要があるよ。03ではなく、3だけをダイヤルしてね。
（選択肢の意味）
1 seize：つかむ、うばい取る
2 omit：省く、抜かす
3 thaw：（凍ったものを）とかす
4 insure：保険をかける
【考え方】
まず見るところ：Bの最後の文の Just dial 3, not 03.
Aは、東京の番号は03でよいかたずねています。code は、ここでは「市外局番（地域ごとに決まっている、電話番号の最初の数字）」のことです。
Bは「そうだよ」と答えたあと、but で注意を付け加えています。
you need to (　) the first number as it's an international call（国際電話だから、最初の数字を（　）必要がある）
as ～ は、ここでは「～だから」です。そのあとの文で、具体的なやり方が説明されています。
Just dial 3, not 03.（03ではなく、3だけをダイヤルして）
03の最初の数字の0をかけないということなので、最初の数字を「省く」必要があると分かります。omit は「省く、抜かす」という意味なので、2が正解です。
この問題の型：具体例とまとめ（03ではなく3→最初の数字を省く）
【ほかの選択肢】
1 seize は「つかむ、うばい取る」です。「最初の数字をつかむ必要がある」となり、3だけをダイヤルするという説明とつながりません。
3 thaw は「（凍ったものを）とかす」です。数字をとかすことはできず、意味が通りません。
4 insure は「保険をかける」です。「最初の数字に保険をかける必要がある」となり、意味が通りません。
【覚えるポイント】
・omit：「省く、抜かす」。名詞は omission（省略）です。
・空所の文のあとに Just ～, not ...（…ではなく、～だけ）のような具体的なやり方が続くときは、そのやり方をひとことで言う語が空所に入ると考えるのが手がかりになります。
