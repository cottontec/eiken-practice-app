【正解】3 routine（決まった手順、日課）
【和訳】
（英文）
Every morning, Zach goes for a run and then takes a shower before he eats breakfast. He follows the same ［routine］ each day.
（訳）
毎朝、ザックはランニングに出かけ、それからシャワーを浴びて、そのあとで朝食を食べます。彼は毎日、同じ（決まった手順）に従っています。
（選択肢の意味）
1 despair：絶望
2 exchange：交換
3 routine：決まった手順、日課
4 minority：少数派
【考え方】
まず見るところ：1文目の Every morning と、2文目の the same (　) each day
Every morning, Zach goes for a run and then takes a shower before he eats breakfast.（毎朝、ザックはランニングに出かけ、それからシャワーを浴びて、朝食を食べる）
ザックは「ランニング→シャワー→朝食」という順番を、毎朝くり返しています。
He follows the same (　) each day.（彼は毎日、同じ（　）に従っている）
follow は「（決まりや手順に）従う」という意味です。毎日同じ順番でくり返していることを表す語が入ると考えられます。
routine は「決まった手順、日課」という意味です。これを入れると、1文目の毎朝の行動を「同じ決まった手順」とまとめた文になります。ですから3が正解です。
この問題の型：具体例とまとめ（毎朝の行動→routine）
【ほかの選択肢】
1 despair は「絶望」です。1文目には落ちこむような話はなく、「毎日同じ絶望に従う」では意味が通りません。
2 exchange は「交換」です。何かを取りかえる話は出てこないので、「同じ交換に従う」では意味が通りません。
4 minority は「少数派」です。「毎日同じ少数派に従う」となり、1文目の毎朝の行動とつながりません。
【覚えるポイント】
・routine：「決まった手順、日課」。
・1文目に具体的な行動が並び、2文目に the same ～ とあれば、2文目は1文目をまとめた言い方になっていることが多いです。
