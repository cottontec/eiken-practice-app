【正解】1 should（if ～ should で「万一～なら」）
【和訳】
A：全部説明したと思いますが、もし新しいソフトウェアについてさらに手助けが必要になったら、遠慮なく言ってください。
B：ありがとうございます、リチャーズさん。
（選択肢の意味）1 （if のあとで）万一～なら　2 ～できる　3 （ought to ～ で）～すべきだ　4 （be 動詞の過去形）～だった
【考え方】
Aは I think I've explained everything（全部説明したと思う）と言っています。そのうえで but if you (　) need any more help ～, just tell me.（でも、もしさらに手助けが～必要なら、言ってください）と続けています。
全部説明したつもりなので、Aは「もう手助けはいらないかもしれないけれど、万一必要になったら」という気持ちで話していると考えられます。
if のあとに should を置くと、「万一～なら、もし～するようなことがあれば」という意味になります。if you should need any more help で「万一もっと手助けが必要になったら」となり、話の流れに合います。should のあとには need という動詞の元の形が続いています。正解は1です。
【ほかの選択肢】
2 can は「～できる」です。if you can need とすると「必要とすることができるなら」となり、意味が通りません。
3 ought は ought to ～ の形で「～すべきだ」という意味になります。空所のあとに to がないので、ought だけでは文になりません。
4 were は be 動詞の過去形です。were need と動詞が2つ並んでしまい、文の形になりません。
【覚えるポイント】
・if ＋ 主語 ＋ should ＋ 動詞の元の形：「万一～なら」。起こる可能性は低いけれど、念のため言っておく、という気持ちを表します。
・just tell me：「遠慮なく言ってください」。
