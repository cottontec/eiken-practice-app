answerText: set aside

【正解】4 set aside（～を取っておいた）
【和訳】
A：帰りが遅くなってごめんね。私抜きで夕食を食べた？
B：うん。みんなとてもおなかがすいていたけれど、あなたのために料理を少し（取っておいた）よ。今から温めるね。
（選択肢の意味）1 （木など）を切り倒した、～を減らした　2 電話を切った、～を（つるして）掛けた　3 （親など）に似ていた　4 ～を取っておいた
【考え方】
Aは帰りが遅くなり、Did you have dinner without me?（私抜きで夕食を食べた？）とたずねています。Bは Yes.（うん）と答えたあと、We were very hungry, but I (　) some food for you.（とてもおなかがすいていたけれど、あなたのために料理を少し（　）した）と続けます。
but（しかし）があるので、「おなかがすいていた」こととは反対向きの内容、つまり「全部は食べなかった」という内容が続くと考えられます。さらに I'll heat it up now.（今からそれを温めるね）とあります。heat up ～ は「～を温める」で、it は取っておいた料理を指しています。
set aside ～ は「～を（あとのために）取っておく」という意味です。I set aside some food for you で「あなたのために料理を少し取っておいた」となり、前後とつながります。set は過去形も set です。ですから4が正解です。
【ほかの選択肢】
1 cut down は「（木など）を切り倒す」「（量）を減らす」です。料理を切り倒すのでは意味が通らず、「減らした」では、Aのために料理を残しておいて今から温めるという話につながりません。
2 hung up は「電話を切った」「～を（つるして）掛けた」です。料理を掛けたのでは意味が通りません。
3 took after は「（親など）に似ていた」です。「あなたのために料理に似ていた」となり、意味が通りません。
【覚えるポイント】
・set aside ～：「～を（あとのために）取っておく」。
・heat up ～：「～を温める」。
