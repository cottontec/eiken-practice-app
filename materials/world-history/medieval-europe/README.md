# 中世ヨーロッパ 演習20題（共通テスト形式・世界史探究）

- `index.html` … 問題・正解・解説を含むWebページ（ブラウザで解いて自動採点）。問題データはページ内の `exam-data` JSON。
- `verify.py` … 機械照合スクリプト。`python3 verify.py` で実行。

## verify.py で確認していること
問題数・配点、選択肢数と解説数、整序問題の年代と正解番号、正誤問題の a/b と正解番号、組合せ問題の一意性、単一選択問題で「正しい」が正解1つだけか、本文中の西暦と年代表の照合。

## 自動では確認できないこと（要確認）
- 年代表 `REF_YEARS` 自体は作問者とは別に書き起こしたものだが、人の記憶に基づく。教科書・用語集で最終確認すること。
- 資料（問8・問17）は史料の要約で、原文の訳ではない。
- 選択肢の言い回しの自然さ、難易度、レイアウトの見え方。
